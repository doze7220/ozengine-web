# OZ Engine

HTML+JS 製ゲームの基礎機能（時間管理、レイヤー、入力、シーン、アセットなど）を提供する、一人開発向けのエンジンです。ゲーム側はルートの `oz/` を触らず、`oz/ENGINE_API.md` だけを見て開発します。ブラウザの Canvas 2D と Vanilla JS（ES Modules）で動き、ビルドは不要です。実行には静的サーバを使います。

---

## 開発の進め方
本リポジトリは、Claude Code を用いた DIR/REQ/RES 駆動の AI 開発ワークフロー（OZFrameWorks AI駆動開発メソッド）で開発している。発注者（人間）向けの見取り図と操作手順は `_doc/PROJECT_README.md` を参照。
