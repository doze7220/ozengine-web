## サンプルと今のエンジンの食い違い（エディタ側で確認した事実）
どちら側で直すかは往復の中で決めます。直し方の判断はそちらに任せます。

### 形式に関するもの
1. **export の形**：サンプルは既定の export だけを持ちます（`export default { ...データ, draw }`）。`js/scenes/FlightScene.js` は `import * as shipSprite` から `shipSprite.draw(ctx)` を呼んでいます。このため、ファイルを差し替えただけでは `draw` が見つかりません（`shipSprite.default.draw` なら呼べます）。
2. **`format`**：サンプルには名前付きの `format` export がありません。既定の export の中に `format: "oz-vector-editor-sprite"`（識別子）と `formatVersion: 1`（版）を持っています。
3. **`draw` の引数**：サンプルは `draw(ctx)` です。`t`・`opts` を渡されても無視するので、呼び出しは壊れません。
4. **既定の export に含まれるもの**：`bounds`（外枠）・`elements`（描画データ）・`source`（作業データ）も入っています。

### 描いた内容に関するもの（形式の問題ではない）
5. **向き**：2.1章は「前方は +X」です。サンプルは機首が上（-Y）を向いているため、そのまま使うと 90° ずれます。
6. **大きさ**：サンプルは約 360×455 px です。手書きの `ship.js` は約 45×36 px なので、約10倍あります。
7. **色**：エディタには色を変える機能がまだなく（P5 で対応）、線は黒（`#000000`）です。エンジンの背景は黒（`index.html` の `background: #000`）なので、線がほぼ見えない見込みです。

5〜7 は、描き直し・確認用の背景色・呼び出し側の拡大縮小などで対応できます。どの方法にするかは、表示を確かめるときに発注者と決めてください。
