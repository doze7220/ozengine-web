### スプライトスタッキング（2026-11-16）
OZ エンジンの描画手法の一つとしては「あり」。ただし実装コストが高いので後回しにする。

* 仕組み：物体を高さ1pxごとの輪切り（スライス）にして、各層を同じ角度で回し、層ごとに1pxずつ上へずらして重ねる。1組の素材で、どの向きにも滑らかに回せる。Canvas 2D の `translate` / `scale` / `rotate` / `drawImage` だけで描ける
* 素材：上・横・前・後ろの4面のドット絵から、スライスを自動で起こせる（4面すべてで塗られている位置だけを残す）。4枚の寸法をぴったり揃え、遠近なし・単色の塗り・1pxの輪郭で描く
* 4面図で作れるのは剛体で、どの方向からも輪郭が出る形（戦闘機・車など）。どの方向からも隠れたへこみ（コックピットのくぼみ、荷台など）は、スライスを手で直す
* 描画の注意：縦方向の縮め（`squash`、0.75 前後）で見下ろす角度を出す。輪郭は重ねた後に1回だけ描く。位置は整数に丸める。前後の並べ替えは地面との接点の y で行う。回らない物は一度描いて普通のスプライトにする
* 人物：最大2頭身のデフォルメにする。頭が大きく丸いので4面図に向き、見下ろしでも判別しやすく、層も少ない
  * 頭・体・手足を別々の積み重ねにして、関節で回す。4面図はパーツごとに1回だけ描き、アニメは関節角度のキーフレームで付けるので、4面で矛盾のないアニメを描き分ける必要がない
  * 前髪は張り出しになるので、頭を「顔」と「髪」の2パーツに分ける。表情は目・口のスライスの差し替えで出す
  * 本当のコストは、関節角度のキーフレームを作るツール。下の「将来の野望」のアニメーション（キーフレーム）とあわせて考える
* 段階案：剛体を普通のスタッキングで描く → 地形を高さマップの積み重ねで描く → 見下ろしと後方視点を連続で切り替える投影式 → パーツ分けの人物とアニメのツール
* 参考資料
  * 解説記事：https://www.spritecook.ai/blog/sprite-stacking-pixel-art （4面図からスライスを作る Python、Godot での描画）
  * 発展形のデモ（戦闘機）：https://forge.ui8.ai/share/frag_1eb8944c-57b1-42ca-a909-5c2d7e517c24 。低解像度のピクセル配列に自前で描く。機体は 34×46px のスライス13枚。地形と雲も高さマップの積み重ね。投影式 `scale = S / (1 + q·depth)` で、`q = 0` が普通のスタッキング、`q > 0` が後方視点になり、視点の切り替えが連続する

### three.js による 3D 描画（2026-11-19）
「Web ゲームを作るとき、three.js を使ってと言うだけで見た目の品質が上がる」という助言を受けた。three.js はブラウザで 3D を描くライブラリで、WebGL を包み、シーン・カメラ・ライト・材質・影・ポストエフェクト（ブルームなど）を部品として扱える。ES Modules で `import` できるので、ビルドなしの方針とはぶつからない。

* 方針の考え方：基本部分は共通のまま使い、描画部分をできるだけ分けておく。ゲーム側が 2D（Canvas 2D）と 3D（three.js）のどちらを使うかを選べる形にできれば楽
  * 共通にできそうなもの：ゲームループ、入力、サウンド、シーンの切り替え、アセットの読み込み
  * 描画に引きずられるもの：座標、カメラ、当たり判定。スプライトJSの `draw(ctx)` も Canvas 2D 前提
  * 2D だけを使うゲームが three.js を読み込まずに済むようにする
* 別リポジトリ（`ozengine-web3d` など）に分けるかどうかは未定。分けるなら、最初はコピーで始め、二重メンテがつらくなってから共通部分の切り出しを考える案がある
* 描画を分けるなら、キャンバスキャッシュ（`CanvasCache`。Canvas 2D 専用で、P4 で `oz/` の独立したモジュールとして入れた）も描画側へ移すことになる。描画を分ける時期は未定で、分けると決めたときに扱う
* エディタの絵：常にカメラを向く板（ビルボード）に貼れば、2D のスプライトのまま 3D 空間に置ける
* 上のスプライトスタッキングと見た目の狙いが重なる。どちらで立体感を出すかを比べる候補になる
* 2D のまま GPU の見栄え（エフェクトなど）だけ欲しい場合は、three.js より 2D 専用の PixiJS が合う
* 試すなら、本体に入れず別フォルダで小さなデモ（箱のキャラが床を歩くだけ、など）を1本作り、見た目の差を見てから決める
