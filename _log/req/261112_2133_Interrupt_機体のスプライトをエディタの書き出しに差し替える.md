2. 本REQの【関連する責務】を把握すること。作業に必要な責務情報はすべてここに記載されている。開発資料（`PROJECT_ARCHITECTURE.md`）は、記載外の責務を確認する必要が生じた場合にのみ参照すること。
3. 実装対象のコードを読み、【関連する責務】に**記述されている内容と実コードが矛盾する**場合は、修正に着手せず、相違点を報告して指示を待つこと。記述にない事項の存在は相違とみなさない。
4. 相違がなければ、【実装要件】に従って実装を開始し、ファイルの差し替えを実行すること。
5. 差し替えが完了したら、Interrupt作業レポートテンプレート（`./_log/TEMPLATE_RES_Interrupt.md`）を元に、作業レポート（`./_log/res/261112_2133_RES_Interrupt_機体のスプライトをエディタの書き出しに差し替える.md`）を新規作成して出力すること。
   * テンプレートの項目に従い、「原因と修正方針」「対象ファイル」「詳細作業内容」を正確に記述すること。
   * 「詳細作業内容」に、差し替えに使ったコマンドと、要件2の確認の結果（実行したコマンドと出力）を書くこと。
6. 開発資料（`PROJECT_ARCHITECTURE.md`）の内容に影響がある場合は、資料本体は修正せず、その旨を作業レポートの『開発資料の更新予定』欄に明記すること。
7. すべての作業が完了したら、チャットにて「実装が完了しました。ビルド・動作確認をお願いします」と報告すること。

## 【実装要件】
OZ Vector Editor が図形の塗りと線なしに対応し、手書きの `ship.js` と同じ絵（白い凹型の多角形と後ろの2つの円、塗りだけで線なし、原点 (0, 0)、機首は +X）をエディタで書き出せるようになった。書き出されたファイルは `_doc/BRIDGE_FROM_VECTOREDITOR_ship.js` に置かれている。

*   **要件1: `assets/sprites/ship.js` の中身を、書き出しファイルの中身で置き換える**
    *  `assets/sprites/ship.js` の中身の全体を、`_doc/BRIDGE_FROM_VECTOREDITOR_ship.js` の中身で置き換える。手書きの中身は1行も残さない。
    *  置き換えは、ファイルを複写するコマンドで行う。中身を読んで打ち直す方法（エディタ用のツールで全文を書き込むなど）は、写し間違いが起きるので使わない。
    *  改行コードは CRLF にする（書き出しファイルは LF なので、複写のときに変換する）。文字コードは UTF-8（BOM なし）のままにする。
    *  改行コード以外は、1文字も変えない。ファイルの先頭のコメントも、エディタが書き出したままにする（憲法3章の「ファイル先頭への『責務定義』記述の義務付け」よりも、同章の「生成物の手編集禁止」を優先する。責務定義の書き足しや、コメントの書き換えは行わない）。
*   **要件2: 差し替えた結果を確かめる**
    *  `assets/sprites/ship.js` から CR を取り除いたものが、`_doc/BRIDGE_FROM_VECTOREDITOR_ship.js` とバイト単位で一致することを、コマンドで確かめる。
    *  `assets/sprites/ship.js` の改行コードが CRLF だけであること（LF だけの行が混ざっていないこと）を、コマンドで確かめる。
    *  構文チェック `node --input-type=module --check < assets/sprites/ship.js` が通ることを確かめる。

## 【関連する責務】
* `assets/sprites/*.js` : 見た目の描画。位置や動き、外部への依存は持たない。既定の export のオブジェクトの `draw(ctx)` を、利用側が呼ぶ。`draw(ctx)` は `ctx` の状態を元に戻して終わる。`draw` 以外のキー（エディタの書き出しに入る `format`・`formatVersion`・`bounds`・`elements`・`source` など）は、エンジンも利用側も読まない。
* `assets/sprites/ship.js` : 現在は手書きのつなぎのスプライトで、エディタの書き出しファイルに差し替える予定のもの。
* `js/scenes/FlightScene.js` : `assets/sprites/ship.js` を `import` し、`drawShip` で位置と回転を `ctx` に設定してから `draw(ctx)` を呼ぶ。本作業では変更しない。
* 憲法3章「生成物の手編集禁止」 : `assets/sprites/` のスプライトJSのうち、OZ Vector Editor が書き出したものは手で編集してはならない。
