## 【実装要件】
元の画像は `D:\ozlab\oztone\build\app_logo.png` である（64 × 64 px の PNG、RGBA。白い「OZ」のロゴで、背景は透明）。OZ Tone のリポジトリのファイルなので、**読むだけで変更しない・本リポジトリにコピーしない**。

*   **要件1: 4つの PNG を作り、`assets/icon/` に置く**
    *  フォルダ `assets/icon/` を新しく作り、次の4つの PNG を置く。ファイル名・大きさはこの表のとおりとする（バトリティアと同じ4つ）。

        | ファイル名 | 大きさ | 作り方 |
        | --- | --- | --- |
        | `favicon-32.png` | 32 × 32 px | 元の画像を**なめらかに縮小**する（Pillow の `Image.LANCZOS`） |
        | `apple-touch-icon-180.png` | 180 × 180 px | 元の画像を**角張らせて拡大**する（Pillow の `Image.NEAREST`） |
        | `icon-192.png` | 192 × 192 px | 同上（`Image.NEAREST`。64 の 3 倍） |
        | `icon-512.png` | 512 × 512 px | 同上（`Image.NEAREST`。64 の 8 倍） |

    *  **背景は付けない。** 透明のまま（RGBA）保存する。余白の追加・色の変更・トリミングもしない（元の画像全体を、そのまま正方形の大きさに変える）。
    *  `apple-touch-icon-180.png` は 64 の整数倍でないため、角張らせた拡大では画素の段の幅が少し不ぞろいになる。発注者は承知済みなので、そのままでよい。
    *  作るのには Python の Pillow（この PC に入っている。`python -I` で実行する）を使う。作るためのスクリプトは本リポジトリに置かない・コミットしない（一時フォルダなどで実行し、作業レポートに手順を書く）。
    *  作った後、4つのファイルの大きさと色の形式（RGBA であること）を Pillow で読み直して確かめる。
    *  4つのファイルには目印（`ozengine sample`）を付けない（PNG なので書く場所もない）。手順書 6章で目印と見本の素材を消した後も残るファイルである。

*   **要件2: `index.html` にアイコンの指定を足す**

          <link rel="icon" type="image/png" sizes="192x192" href="./assets/icon/icon-192.png">
          <link rel="icon" type="image/png" sizes="512x512" href="./assets/icon/icon-512.png">
          <link rel="apple-touch-icon" sizes="180x180" href="./assets/icon/apple-touch-icon-180.png">
