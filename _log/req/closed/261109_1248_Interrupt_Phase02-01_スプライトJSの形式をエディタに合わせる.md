## 【実装要件】
OZ Vector Editor が書き出すスプライトJSは、名前付きの export を持たず、既定の export だけを持つ（`export default { ...データ, draw }`。`draw(ctx)` が `ctx` の現在の変換の上に原点 (0, 0) を基準に描き、`ctx` の状態を元に戻す）。書き出したファイルを `assets/sprites/` に置き換えるだけでゲームの土台に表示できるように、読み込み側と手書きの `ship.js` をこの形に合わせる。

*   **要件1: 読み込み側を既定の import に変える（`js/scenes/FlightScene.js`）**
    *  `import * as shipSprite from 'assets/sprites/ship.js';` を、既定の export を受け取る import（`import shipSprite from 'assets/sprites/ship.js';`）に変える。
    *  `drawShip` の中の呼び出しは `shipSprite.draw(ctx)` のままとする（引数は `ctx` だけを渡す）。位置・回転を `ctx` に設定してから呼ぶ流れは変えない。
    *  ファイル先頭の `/* ozengine sample */` の目印は残す。それ以外の行は変更しない。
*   **要件2: 手書きの `assets/sprites/ship.js` を既定の export の形に書き直す**
    *  憲法3章「生成物の手編集禁止」の例外として、本REQで `assets/sprites/ship.js` の書き直しを明示的に許可する。
    *  名前付きの export（`format`・`draw`）をなくし、既定の export を `draw` だけを持つオブジェクトにする（`export default { draw };` の形）。`format`・`formatVersion` などのデータは持たせない（エンジンも利用側も読まないため。この扱いは後続のサブフェイズで規約として定める）。
    *  `draw` の引数は `ctx` だけにする（予約引数 `t`・`opts` はなくす）。
    *  描く内容（白の塗り、多角形の頂点 (22, 0)・(-23, 18)・(-13, 0)・(-23, -18)、半径 3 の円2つの中心 (-18, -12)・(-18, 12)）と、`ctx.save()`／`ctx.restore()` で状態を戻すことは今と同じにする。タイトルとプレイで、機体が今までと同じ大きさ・向き・見た目で表示されること。
    *  ファイル先頭の責務定義と、`draw` および既定の export の JSDoc は、新しい形に合わせて書き直す（責務の内容そのもの「機体の見た目を描画する手書きのスプライト。位置や動きは持たない。外部に依存しない」は変えない）。
*   **要件3: エディタの書き出しファイルとの差し替えでエラーが出ないこと**
    *  要件1・2の後、OZ Vector Editor が書き出した `_doc/bridge_samples/ship.js`（参考として閲覧してよい。変更してはならない）を `assets/sprites/ship.js` の代わりに置いても、`js/` を変えずにエラーなく機体の位置に絵が描かれる状態になっていること。実際の差し替えは行わなくてよい（確認は発注者のテストプレイで行う）。
*   **要件4: 目印の付いた部分を消しても起動できる状態を保つ**
    *  `ozengine sample` の目印の付いた部分をすべて消してもエラーなく起動できる状態を、変更後も保つこと（`assets/sprites/ship.js` を参照するのは目印の付いた `js/scenes/FlightScene.js` だけである）。

## 【関連する責務】
* `assets/sprites/*.js` : 見た目の描画だけを持つ、外部依存のない1ファイルのESモジュール。位置や動き、外部への依存は持たない。エンジンは中身を解析せず、利用側が `draw` を呼ぶ。座標の原点は (0, 0)、機体の前方は +X。位置と回転は呼ぶ側が `ctx` に設定する。
  * ※ 開発資料 2.1章には旧形式（名前付きの `format` と `draw(ctx, t, opts)`）が書かれているが、2.1章は後続のサブフェイズで改訂する。本作業では本REQの形式を優先し、2.1章との食い違いは相違として報告しなくてよい（RESの『開発資料の更新予定』には、2.1章の export の表が変わる旨を記載すること）。
* `js/scenes/FlightScene.js` : タイトルとプレイに共通の、機体・星・トレイル・風の保持と更新と描画、カメラ、ミュートキー。`drawShip` で機体の位置と向きを `ctx` に設定してからスプライトの `draw` を呼ぶ。
* import map（`index.html`）: `"assets/"` が `./assets/` に対応する。
