### 要件5: 機体の動き（タスク1 `js/entities/`）
*   **`Ship`（`js/entities/Ship.js`）:** 操作の違いを知らない。描画しない。
    *   フィールド: `x = 0`、`y = 0`、`angle = 0`、`targetAngle = 0`、`speed = BASE_SPEED`。
    *   `turn(delta)` : `targetAngle += delta`。
    *   `boost()` : `speed < BOOST_READY_BELOW` のときだけ `speed = BOOST_SPEED` にして `true` を返す。それ以外は `false` を返す。
    *   `update()` : 1ティック進める。`diff = targetAngle - angle` を `while` で `-π`〜`π` に丸める → `angle += diff * TURN_RATE` → `speed += (BASE_SPEED - speed) * SPEED_RECOVERY` → `x += cos(angle) * speed`、`y += sin(angle) * speed`。
    *   定数: `BASE_SPEED = 12`、`TURN_RATE = 0.08`、`BOOST_SPEED = 40`、`BOOST_READY_BELOW = 15`、`SPEED_RECOVERY = 0.05`。**1ティックあたりの値で、`tickRate` 60 を前提とすることをコメントに書く。**
*   **自動操縦（`js/entities/autopilot.js`）:** 状態を持たない関数 `steerByAutopilot(controls)` を export する。`controls` は `{ turn(delta: number): void, boost(): boolean }`（typedef `ShipControls` をこのファイルに書く）。
    *   `Math.random() < TURN_CHANCE`（`0.03`）なら `controls.turn((Math.random() - 0.5) * TURN_RANGE)`（`TURN_RANGE = Math.PI * 1.5`）。
    *   `Math.random() < BOOST_CHANCE`（`0.01`）なら `controls.boost()`。戻り値は使わない。
    *   確率は1ティックあたりの値であることをコメントに書く。
*   **旋回とブーストの指示の形:** 自動操縦とキー操作の両方が `FlightScene` の `turn(delta)`・`boost()` を呼ぶ（要件2、タスク4）。
    *   `FlightScene.turn(delta)` は `ship.turn(delta)` を呼ぶ。
    *   `FlightScene.boost()` は `ship.boost()` が `true` なら `wind.spawn(ship)` を呼んで `true` を返し、そうでなければ `false` を返す。
    *   `TitleScene.update` は `steerByAutopilot(this)` を呼ぶ。戻り値を見ないので SE は鳴らない。
    *   `PlayScene.onKeyDown('Space')` は `if (this.boost()) Sound.playSe('se');` とする。速さの条件で不発のときは SE も鳴らない。
    *   `PlayScene` の定数: `TURN_PER_TICK = 0.06`（1ティックあたりの目標の角度の変化であることをコメントに書く）。
*   **ティック内の順序:** `TitleScene.update(dt)`・`PlayScene.update(dt)` は、先に操作の指示を出してから `super.update(dt)` を呼ぶ。

どれも `vernier.html` の該当行を読み、値と計算をそのまま移す。`width`・`height` は `screen.width`・`screen.height` に置き換える。ゲーム進行に影響する処理を持たない。`Ship` を import せず、`{ x, y, angle }` を持つオブジェクトとして受け取る。

    *   `constructor(screen)` : 250 個を作る（`x`: `random * width`、`y`: `random * height`、`size`: `random * 1.5 + 0.5`、`opacity`: `random`、`depth`: `random * 0.8 + 0.2`）。
    *   `draw(ctx, camera)` : 先に背景を塗ってから星を描く。`update` はない。
    *   **背景:** 元の CSS `linear-gradient(135deg, #02050a 0%, #0a1128 100%)` と同じ見え方にする。CSS の角度指定の規則により、`r = (width + height) / 4` として、`createLinearGradient(width / 2 - r, height / 2 - r, width / 2 + r, height / 2 + r)` に `#02050a`（0）と `#0a1128`（1）を置く。1280×720 では `(140, -140)` から `(1140, 860)` になる。
*   **`Wind`（`js/effect/Wind.js`。元: L54-123、L162-168、L377-384）:**
    *   `constructor(screen)` : 線の配列を空で持つ。
    *   `spawn(ship)` : `Math.floor(random * 20 + 30)` 本を足す。各線の値と発生位置は `WindLine` の constructor のとおり。
    *   `update()` : 全線を進める（`x`・`y`、`length += 10`、`life++`）。`life > maxLife` の線を配列から外す。
    *   `draw(ctx, camera)` : 各線を描く（フェード、`screen` の合成、白のグラデーション、ベジェの形）。線は `save` / `restore` で囲む。
    *   線はファイル内の非公開のクラス `WindLine` にまとめる（`update()`・`draw(ctx, camera)`）。ファイルの外へ export するのは `Wind` だけとする。
*   **`Trail`（`js/effect/Trail.js`。元: L155-157、L190-206、L210-309）:**
    *   `update(ship)` : 機体座標の `(-43, -12)`（左）と `(-43, 12)`（右）をワールド座標に変換して、左右の履歴の先頭へ足す。60 点を超えたら末尾を外す。
    *   `draw(ctx, camera)` : `save` → `translate(camera.x, camera.y)` → 左の帯 → 右の帯 → `restore`。
    *   帯の描画はファイル内の非公開の関数に分ける（法線と左右の輪郭を求める関数と、塗る関数）。輪郭の配列は関数内のローカル変数とし、インスタンスに保存しない。

    *   噴射口との隙間はそのまま残す（発注者の決定）。起点を変えない。
*   **`FlightScene` からの呼び出し:** `update(dt)` は `ship.update()` → `trail.update(ship)` → `wind.update()` の順とする。`dt` は使わない（値が1ティック固定のため）。JSDoc にその旨を書く。
