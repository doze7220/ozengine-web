## 1. 作業目的
今の土台の開発用パネル（`js/scenes/devPanel.js`）は見本なので、新規プロジェクトで見本を消すと無くなる。これを、どのゲームでも使う最小の開発用パネル（FPS と速度）の雛形に変え、見本を消した後も `js/` に残るようにする。土台の項目（等速に戻す、情報）は、目印を付けた別のファイルから雛形に足す。

あわせて、土台の開発用の入口（FPS の表示のキー `F`、スローのキー `S`、メニューの項目「開発用パネル」）を、開発モード（`Engine.debug` が `true`）のときだけ使えるようにする。速度が2倍や停止にもなるので、プレイ画面の右上の「スロー」の文字を、今の速度を出す表示に変える。

`oz/`、`js/main.js`、`MenuScene.js`、`WindowScene.js`、手順書（`_doc/newgame/`）は変えない。

### 要件1・要件2・要件3: 開発用パネルの雛形（`js/scenes/devPanel.js`）

#### 公開するもの
| 名前 | 内容 |
| --- | --- |
| `openDevPanel({ layer, addParts, tabs })` | パネルを開く。`layer`（窓を描くレイヤー名。必須）、`addParts`（「基本」に続けて部品を足す関数。省略可）、`tabs`（足すタブの配列。省略可）。開発モードでなければ何もしない |
| `FPS_POSITION_CHOICES` | 位置の選択肢（凍結した配列。要素は凍結した `{ label, value }`） |
| `fpsPositionText()` | 今の位置の文字 |
| `fpsText(value)` | `Engine.fps` の値の文字（`null` なら `--`） |
| `timeScaleText(value)` | `timeScale` の値の文字（`×` を前に付ける） |

* **`addParts(area, start)`:** `area` は「基本」のスクロールする領域のオブジェクト、`start` は `{ x, y, width }`（領域の中身の左上が原点。雛形の部品のすぐ下の行の上端と、部品の左端・幅。値は `{ x: 12, y: 612, width: 516 }`）。
* **`tabs` の要素 `{ label, build }`:** 「基本」の右に、配列の順に並ぶ。`label` は `addTabs` の `labels` の要素と同じ形（文字列か、文字列を返す関数）。`build(tab, rect)` は、`tab` がそのタブのオブジェクト（`addTabs` の戻り値の要素）、`rect` が部品を置ける範囲 `{ x, y, width, height }`（窓の内側の左上が原点。タブの列の下の矩形。値は `{ x: 24, y: 112, width: 552, height: 388 }`）。
* `addParts` と `build` は、窓を作るとき（窓のシーンの `init`）に1回ずつ呼ばれる。渡す `start`・`rect` は呼び出しごとに新しいオブジェクトにする。
* 引数の独自の検証はしない（書き間違いは `Ui` のエラーで分かる）。

#### 大きさと位置（論理座標。すべて定数にする）
| 対象 | 値 |
| --- | --- |
| 窓 | 600×600、タイトル「開発用パネル」、標準の見た目（`look`・`textSize` などは渡さない）、`closeOnOutside` は既定（窓の外の押下で閉じる）、`onClose` は `Engine.popScene()` |
| タブの列 | x 24・y 12・幅 552（高さは既定の 88） |
| タブの列の下の矩形 | x 24・y 112・幅 552・高さ 388（窓の内側の高さ 512 の下端に 12 を空ける） |
| 「基本」の領域 | タブの列の下の矩形と同じ |
| 領域の中の部品 | x 12・幅 516（右端の 24 を空ける。手前 12 と位置の表示の帯 12）、1行目の上端 12、行の間隔 100（部品の高さ 88 と間 12） |
| 呼ぶ側の部品の始まり | 6行の下（12 + 100 × 6 = 612） |

#### 「基本」の部品（上から順。項目はこれより増やさない）
| 行 | 操作 | `label`（または選択肢） | `read` | `write`・`format` |
| --- | --- | --- | --- | --- |
| 0 | `addCheckbox` | FPS を表示する | `Engine.fpsVisible` | `Engine.fpsVisible` に書く |
| 1 | `addValue` | 表示の位置 | `fpsPositionText` | - |
| 2 | `addChoices` | `FPS_POSITION_CHOICES` | `Engine.fpsPosition` | `Engine.fpsPosition` に書く |
| 3 | `addValue` | FPS | `Engine.fps` | `format: fpsText` |
| 4 | `addValue` | 速度 | `Engine.timeScale` | `format: timeScaleText` |
| 5 | `addChoices` | 停止・×0.25・×0.5・×1・×2（値は 0・0.25・0.5・1・2） | `Engine.timeScale` | `Engine.timeScale` に書く |

* 速度の選択肢の一覧は雛形の中の定数（公開しない）。「停止」以外の `label` は `timeScaleText(value)` で作る。
* `Engine.timeScale` が一覧に無い値のときは、選択肢の列はどれも選ばれない（`===` で比べる。`oz/ENGINE_API.md` 26章）。「速度」の表示は今の値を出す。追加の処理は要らない。
* 選んだ状態は保存しない（`Storage` を使わない）。

#### コードの形（この形で書く。省略した JSDoc・定数は実装時に全部書く）

```js
/**
 * 責務: 開発用パネルの雛形の窓の中身（窓の設定、「基本」の部品の並びと位置、値のつなぎ方、呼ぶ側の部品とタブの受け入れ）と開き方、
 * FPS の位置の選択肢と、FPS・速度の文字（土台も読む）。
 */
import { Engine, Ui } from 'oz';
import { openWindow } from './WindowScene.js';

// （ここに「足し方と注意」のコメントと typedef、定数）

export const FPS_POSITION_CHOICES = Object.freeze([
  Object.freeze({ label: '左上', value: 'top-left' }),
  Object.freeze({ label: '右上', value: 'top-right' }),
  Object.freeze({ label: '右下', value: 'bottom-right' }),
  Object.freeze({ label: '左下', value: 'bottom-left' }),
]);

const SPEED_CHOICES = [
  { label: LABEL_STOP, value: 0 },
  ...[0.25, 0.5, 1, 2].map((value) => ({ label: timeScaleText(value), value })),
];

export function fpsPositionText() {
  return FPS_POSITION_CHOICES.find((choice) => choice.value === Engine.fpsPosition).label;
}

export function fpsText(value) {
  return value === null ? FPS_NONE_TEXT : String(value);
}

export function timeScaleText(value) {
  return `×${value}`;
}

function addBasicParts(area) { /* 表の6行を足し、{ x, y, width }（呼ぶ側の部品の始まり）を返す */ }

function createDevPanelWindow({ addParts, tabs = [] }) {
  const win = Ui.createWindow({ title: PANEL_TITLE, width: PANEL_WIDTH, height: PANEL_HEIGHT, onClose: () => Engine.popScene() });
  const [basicTab, ...addedTabs] = win.addTabs({
    x: BODY.x, y: TAB_Y, width: BODY.width,
    labels: [LABEL_BASIC, ...tabs.map((tab) => tab.label)],
  });
  const area = basicTab.addScroll({ ...BODY });
  const start = addBasicParts(area);
  if (addParts) addParts(area, start);
  tabs.forEach((tab, i) => tab.build(addedTabs[i], { ...BODY }));
  return win;
}

export function openDevPanel({ layer, addParts, tabs }) {
  if (!Engine.debug) return;
  openWindow({ layer, createWindow: () => createDevPanelWindow({ addParts, tabs }) });
}
```

* `BODY` は「タブの列の下の矩形」の凍結した定数。`addBasicParts` の中は、今のコードと同じく `area.addCheckbox({ x, y, width, ... })` のように1つずつ呼ぶ形で書く。

#### 雛形のファイルの中のコメント（必ず書く内容）

2. 足し方: このファイルを書き換えずに、`addParts` と `tabs` で足す。どちらも省略できる。次の例を書く（`clearEnemies`・`enemies` は例の名前であることを書く）。

    ```js

      layer: 'ui',
      addParts: (area, { x, y, width }) => {
        area.addButton({ x, y, width, label: '敵を消す', onPress: clearEnemies });
        area.addValue({ x, y: y + 100, width, label: '敵の数', read: () => enemies.length });
      },
      tabs: [
        {
          label: '音',
          build: (tab, rect) => {
            tab.addValue({ x: rect.x, y: rect.y, width: rect.width, label: 'BGM の音量', read: () => Sound.bgmVolume });
          },
        },
      ],
    });
    ```

    部品の高さは既定で 88 なので、次の行は 100 ほど下に置く。`rect` に収まらない数なら `tab.addScroll({ ...rect })` の中に置く（領域の中の位置は、領域の中身の左上が原点）。`addParts`・`build` は窓を作るときに呼ばれるので、部品を足すだけにし、シーンの操作をしない。

5. 注意（パッド）: 後ろの画面のパッドの配置が違うときの扱いは、`WindowScene.js` の説明（`init` の JSDoc）に従う。
