    | boot 画面を押す・離す（PC はキーでも） | 押すと音が鳴り、タイトルへ進む |
    | タイトルを見る | 星・トレイル・機体・風が動き、ゲーム名・画像・「スタート」ボタンが重なり、BGM が流れる |
    | 「スタート」か画面を押す | プレイ画面になる（BGM は流れ続ける） |
    | PC: 左右の矢印キー | 左右に旋回する |
    | PC: `Space` | ブーストし、音が鳴り、風が出る |
    | PC: `P` を2回 | メニューが開き、もう一度で閉じる |
    | 画面の「メニュー」ボタン | メニューが開く。項目は「閉じる」「設定」「タイトルに戻る」の3つ |
    | メニューの「設定」 | 設定画面が開き、音量・ミュート・初期値に戻すが使え、閉じるとプレイに戻る |
    | PC: `M` を2回 | 音が消えて右上に「ミュート中」が出て、もう一度で戻る |
    | メニューの「タイトルに戻る」 | タイトルに戻る |

    | 操作 | 期待する結果 |
    | --- | --- |
    | プレイ中にスティックを左右に倒す | 左右に旋回する |
    | プレイ中にパッドのボタンを押す | ブーストし、音が鳴り、風が出る |
